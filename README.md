# Substance 3D Painter V12 快捷键查询

一个纯 HTML 快捷键查询工具，**无需安装任何依赖**，手机和 PC 浏览器均可直接打开使用。

## 使用方式

直接打开 `index.html` 即可，或将文件传到手机浏览器中。

## 功能

- **114 条快捷键**，覆盖 10 个常用分类
- **实时搜索**：按快捷键名称、按键组合或功能描述筛选
- **分类筛选**：视图控制、笔刷工具、图层、遮罩、纹理材质、文件等
- **深色模式**：跟随系统主题自动切换
- **触控优化**：移动端单手操作适配
- **离线可用**：单文件，不依赖网络

## 快捷键分类

| 分类 | 说明 |
|------|------|
| 视图控制 | 3D/2D/UV视图切换、聚焦、网格 |
| 笔刷与工具 | B画笔、E橡皮擦、[]大小、{}透明度 |
| 图层操作 | 新建、复制、编组、合并、顺序 |
| 遮罩与选择 | 添加/反转遮罩、全选、反选 |
| 纹理与材质 | 纹理集、导出、材质选择 |
| 资源与面板 | F5-F12功能区、搜索、截图 |
| 文件操作 | 新建、打开、保存、导出 |
| 显示与设置 | 着色、线框、灯光、环境 |
| 编辑操作 | 撤销、复制、粘贴、删除 |
| 烘焙 | 烘焙纹理、快速烘焙 |
